How it works

Bring both ends online

01Create a line on the receiving device and keep this page open.
02On the sending device, enter the line code, choose a file or write a note, then send.
03A WebRTC internet call plays a fax-style handshake and modem soundtrack. The file travels reliably over an encrypted WebRTC data channel.
For the fax feeling: audible modem tones are streamed between devices; file contents use a separate reliable internet data channel so transfers aren't limited to the slow speed of real phone-line fax. It needs HTTPS and an active connection to the PeerJS signaling service. This is a fun fax-inspired transfer, not a standards-certified fax or telephone call.
The four-digit line is a short public room code—avoid sensitive documents. If the code is busy, choose another. Audio can be muted; data transfer still works.
