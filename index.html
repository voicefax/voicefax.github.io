Upload an image or PDF. The page is rasterized to fax width and encoded as T.4 Group 3 one-dimensional MH. Export the fax data, or play/download the fax calling tone.

Audio generated here is the real 1100 Hz CNG fax calling tone only. It does not carry the encoded page; fax page audio requires a V.17/V.29 modem and T.30 protocol, which this standalone app does not implement.

02 / LISTEN & DECODE

Fax audio to page

Upload a WAV recording to listen to it locally and inspect the file. The app will explain whether it can recover a page.

Audio player · no demodulator
No file selected

Listening and WAV inspection are supported. Recovering a page from audio requires V.17/V.29/V.27ter demodulation plus T.30 handling; those standards are not implemented, so this app will not pretend that a tone or recording decoded into a page.

Implemented

ITU-T T.4 one-dimensional Modified Huffman run-length encoding and decoding, per-line EOL, packed bits, and RTC on generated pages. Encoded downloads use a documented VOICEFAX .vfax wrapper around the T.4 MH bitstream. PNG/JPEG and VFAX processing run locally. PDF.js is loaded from a CDN only when PDF import is needed.

Not implemented

T.4 two-dimensional MR, TIFF-G3 packaging, T.30 session protocol, V.17/V.29/V.27ter page modulation, and audio demodulation to reconstruct a fax page. The calling-tone WAV is CNG signaling only, not a document transmission. A WAV upload is playable and inspectable, but not decoded as fax data.
