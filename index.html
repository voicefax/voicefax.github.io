How it works

Make the connection

01Open this site in two tabs in the same browser and device; share the four-digit line number.
02Join using that number. Keep both tabs open while you send.
03Choose a PDF or image. It transfers directly between the tabs, then opens with a fax-style monochrome look.
Important: This GitHub Pages demo transfers files using browser code (BroadcastChannel), not through sound. Fax-like tones and static are audio effects only. Real acoustic fax transmission and cross-device connections require a modem protocol and a signaling/telephony service.
Files are sent between same-origin tabs on this browser and aren't uploaded to a server. Only send files you have permission to share.
