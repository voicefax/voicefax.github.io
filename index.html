How it works

Make the connection

01On the receiving device, join the same code and press Listen. Allow microphone access.
02On the sending device, select a file or write a note, then press send. The receiver answers the acoustic handshake.
03Keep both devices nearby and undisturbed until the transfer finishes. Received items appear below.
Sound-only: GGWave sends the actual data as audio. The handshake confirms a receiver heard the sender; it doesn't count everyone on a line. Each packet includes its session and sequence number, and the receiver checks the complete file before offering it. Room noise or devices can still cause failed transfers.
HTTPS and microphone permission required. Anyone nearby can listen to a line; it isn't encrypted. Avoid confidential files. 10 MB files could take many days over sound.
