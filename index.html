How it works

Make the connection

01On the receiving device, join the same line and press Listen. Allow microphone access.
02On the sending device, choose a file or write a note. The receiver answers with an acoustic handshake.
03Keep both devices nearby and quiet until all file tones finish.
Sound-only demo: file bytes travel as audio using the open-source GGWave modem (audible FSK with error correction), not a network transfer. A four-digit line is only an acoustic channel label; anyone nearby who listens on that code may receive it. This is not a standards-compliant telephone fax. Microphone and speaker quality, room noise, browser support, and acoustic bandwidth affect results. 10 MB files could take many hours and are not practical for acoustic transfer.
Microphone access requires HTTPS. Transfer is not encrypted. Avoid sensitive files. For longer or reliable transfers, use a network connection instead.
